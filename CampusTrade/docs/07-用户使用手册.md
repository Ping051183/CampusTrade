# 校园二手交易平台 - 用户使用手册

## 1. 快速入门

### 1.1 注册账号
1. 访问平台首页，点击右上角「注册」按钮
2. 填写用户名（3-50个字符）、密码（6位以上）
3. 可选填昵称、手机号、邮箱、学号、学校等信息
4. 点击「注册」完成注册

### 1.2 登录账号
1. 点击右上角「登录」按钮
2. 输入用户名和密码
3. 点击「登录」进入平台

### 1.3 浏览商品
- 首页展示最新商品和分类导航
- 点击「商品市场」查看所有在售商品
- 使用搜索框按关键词搜索
- 点击分类进行筛选

## 2. 发布商品

### 2.1 发布步骤
1. 登录后，点击「发布商品」按钮
2. 填写商品标题（必填）
3. 选择商品分类（必填）
4. 设置售价（必填）
5. 可选填原价
6. 上传商品图片（支持1-6张）
7. 填写商品描述（至少10个字）
8. 点击「提交审核」

### 2.2 商品状态说明
- **待审核**：提交后需要管理员审核
- **在售**：审核通过，其他用户可以浏览购买
- **已下架**：手动下架或管理员下架
- **已售出**：已被其他用户购买
- **已驳回**：审核未通过，可能需要修改后重新提交

## 3. 购买商品

### 3.1 购买流程
1. 在商品详情页点击「立即购买」
2. 确认订单信息
3. 点击确认完成下单
4. 在「我的订单」中查看订单状态

### 3.2 订单状态
- **待付款**：下单成功，等待付款
- **已付款**：买家已付款
- **已收货**：买家确认收货
- **已取消**：订单已取消

### 3.3 确认收货
在「我的订单」中找到对应订单，点击「确认收货」完成交易。

## 4. 收藏商品
1. 在商品详情页点击「收藏」按钮
2. 在「我的收藏」中查看所有收藏的商品
3. 再次点击可取消收藏

## 5. 个人信息管理
1. 点击右上角头像进入个人信息页
2. 可以修改昵称、手机号、邮箱、学号、学校
3. 可以上传头像
4. 「修改密码」功能可更改登录密码

## 6. 管理后台（管理员专用）

### 6.1 访问方式
使用管理员账号登录，点击导航栏「管理后台」

### 6.2 功能说明
- **数据统计**：查看平台运营数据总览
- **用户管理**：查看用户列表，启用/禁用用户
- **商品管理**：审核商品，管理所有商品
- **举报管理**：处理用户举报
- **公告管理**：发布和管理系统公告

## 7. 常见问题

### Q: 忘记密码怎么办？
A: 联系管理员重置密码。

### Q: 发布的商品什么时候能审核通过？
A: 管理员会在1-2个工作日内完成审核。

### Q: 可以取消订单吗？
A: 在「待付款」状态下可以取消订单。

### Q: 如何修改已发布的商品？
A: 在「我的商品」中点击编辑按钮进行修改，修改后需要重新审核。
