# 校园二手交易平台 - 系统设计文档

## 1. 系统架构

### 1.1 整体架构
采用前后端分离架构：
- 前端：Vue3 + Vite + Element Plus
- 后端：Spring Boot 3 + MyBatis Plus
- 数据库：MySQL 8
- 缓存：Redis
- 部署：Docker + Docker Compose + Nginx

### 1.2 架构图
```
┌─────────────┐     ┌──────────┐     ┌──────────┐
│  浏览器     │────▶│ Nginx    │────▶│ 后端服务  │
│ (Vue3 SPA)  │     │ (80端口) │     │ (8080端口)│
└─────────────┘     └──────────┘     └─────┬────┘
                                           │
                                    ┌──────┴──────┐
                                    │  MySQL + Redis│
                                    └─────────────┘
```

### 1.3 技术栈选型
| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 前端框架 | Vue | 3.4.x | Composition API |
| 构建工具 | Vite | 5.x | 快速开发服务器 |
| UI组件 | Element Plus | 2.4.x | 企业级UI库 |
| 状态管理 | Pinia | 2.x | Vue3官方推荐 |
| 路由 | Vue Router | 4.x | SPA路由管理 |
| HTTP | Axios | 1.6.x | 请求拦截封装 |
| 后端框架 | Spring Boot | 3.2.x | 企业级开发 |
| ORM | MyBatis Plus | 3.5.x | 高效数据库操作 |
| 安全 | Spring Security | 6.x | JWT无状态认证 |
| 数据库 | MySQL | 8.x | 关系型数据库 |
| 缓存 | Redis | 7.x | 数据缓存 |
| 部署 | Docker | 24.x | 容器化部署 |

## 2. 后端架构

### 2.1 项目结构
```
src/main/java/com/campustrade/
├── common/          # 公共类（Result, PageResult）
├── config/          # 配置类（MyBatis, Redis, CORS, Swagger）
├── constant/        # 常量类（角色、状态）
├── controller/      # 控制器层
├── dto/             # 数据传输对象
├── entity/          # 实体类
├── exception/       # 异常处理
├── mapper/          # 数据访问层
├── security/        # 安全认证
├── service/         # 业务逻辑层
├── utils/           # 工具类
└── vo/              # 视图对象
```

### 2.2 请求处理流程
```
请求 → CORS过滤器 → JWT认证过滤器 → Controller → Service → Mapper → DB
                                              ↓
                                      GlobalExceptionHandler (异常时)
                                              ↓
                                      统一Result响应格式
```

## 3. 前端架构

### 3.1 项目结构
```
src/
├── api/        # API请求模块
├── components/ # 公共组件
├── router/     # 路由配置
├── stores/     # Pinia状态管理
├── utils/      # 工具类
└── views/      # 页面组件
    └── admin/  # 管理后台页面
```

### 3.2 路由守卫
- 需要登录的页面：配置 `meta.requiresAuth: true`
- 需要管理员权限：配置 `meta.requiresAdmin: true`
- 未登录自动跳转登录页，登录后跳回原页面
