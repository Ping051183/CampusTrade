# 校园二手交易平台 - 数据库设计文档

## 1. 数据库概览
- 数据库名：`campus_trade`
- 字符集：`utf8mb4`
- 排序规则：`utf8mb4_unicode_ci`

## 2. 表结构设计

### 2.1 用户表 (user)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| password | VARCHAR(255) | NOT NULL | 密码(BCrypt) |
| nickname | VARCHAR(50) | | 昵称 |
| avatar | VARCHAR(255) | | 头像URL |
| phone | VARCHAR(20) | | 手机号 |
| email | VARCHAR(100) | | 邮箱 |
| student_no | VARCHAR(50) | | 学号 |
| school | VARCHAR(100) | | 学校 |
| role | TINYINT | DEFAULT 1 | 0-管理员 1-用户 |
| status | TINYINT | DEFAULT 1 | 0-禁用 1-启用 |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |

### 2.2 商品表 (goods)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 商品ID |
| title | VARCHAR(200) | NOT NULL | 标题 |
| description | TEXT | | 描述 |
| category_id | BIGINT | FK→category | 分类ID |
| price | DECIMAL(10,2) | NOT NULL | 售价 |
| original_price | DECIMAL(10,2) | | 原价 |
| seller_id | BIGINT | FK→user | 卖家ID |
| images | VARCHAR(2000) | | 图片(逗号分隔) |
| status | TINYINT | DEFAULT 0 | 0-待审 1-在售 2-下架 3-售出 4-驳回 |
| view_count | INT | DEFAULT 0 | 浏览次数 |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |

### 2.3 分类表 (category)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 分类ID |
| category_name | VARCHAR(50) | NOT NULL | 分类名称 |
| sort | INT | DEFAULT 0 | 排序号 |

预置数据：数码产品、图书教材、生活用品、体育用品、宿舍用品、服装鞋帽、其他

### 2.4 收藏表 (favorite)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 收藏ID |
| user_id | BIGINT | FK→user | 用户ID |
| goods_id | BIGINT | FK→goods | 商品ID |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |
| UNIQUE | (user_id, goods_id) | | 联合唯一 |

### 2.5 订单表 (orders)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 订单ID |
| order_no | VARCHAR(50) | UNIQUE | 订单编号 |
| buyer_id | BIGINT | FK→user | 买家ID |
| seller_id | BIGINT | FK→user | 卖家ID |
| goods_id | BIGINT | FK→goods | 商品ID |
| amount | DECIMAL(10,2) | NOT NULL | 金额 |
| status | TINYINT | DEFAULT 0 | 0待付1已付2发货3收货4取消5完成 |
| remark | VARCHAR(500) | | 备注 |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |

### 2.6 评论表 (comment)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 评论ID |
| goods_id | BIGINT | FK→goods | 商品ID |
| user_id | BIGINT | FK→user | 用户ID |
| content | VARCHAR(500) | NOT NULL | 内容 |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |

### 2.7 举报表 (report)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 举报ID |
| goods_id | BIGINT | FK→goods | 商品ID |
| reporter_id | BIGINT | FK→user | 举报人 |
| reason | VARCHAR(500) | NOT NULL | 原因 |
| status | TINYINT | DEFAULT 0 | 0待处理1已处理2驳回 |
| handle_result | VARCHAR(500) | | 处理结果 |
| handler_id | BIGINT | | 处理人 |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |

### 2.8 公告表 (notice)
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK | 公告ID |
| title | VARCHAR(200) | NOT NULL | 标题 |
| content | TEXT | NOT NULL | 内容 |
| create_time | DATETIME | DEFAULT NOW | 创建时间 |

## 3. 索引设计
- user: username(UNIQUE), role, status, school
- goods: category_id, seller_id, status, create_time
- favorite: (user_id, goods_id) UNIQUE
- orders: order_no(UNIQUE), buyer_id, seller_id, status

## 4. ER关系说明
- 用户(1) → 商品(N)：一对多（卖家发布商品）
- 分类(1) → 商品(N)：一对多（商品所属分类）
- 用户(1) → 收藏(N)：一对多（用户收藏）
- 商品(1) → 收藏(N)：一对多
- 买家(1) → 订单(N)：一对多（购买订单）
- 卖家(1) → 订单(N)：一对多（出售订单）
