# 校园二手交易平台 - 部署文档

## 1. 部署方式

### 1.1 方式一：Docker Compose 一键部署（推荐）

#### 前置条件
- Docker 24+
- Docker Compose 2+

#### 部署步骤
```bash
# 1. 进入项目根目录
cd CampusTrade

# 2. 构建并启动所有服务
docker-compose up -d

# 3. 查看服务状态
docker-compose ps

# 4. 查看日志
docker-compose logs -f
```

#### 访问地址
- 前端页面：http://localhost
- 后端API：http://localhost:8080
- API文档：http://localhost:8080/doc.html

#### 停止服务
```bash
docker-compose down
```

### 1.2 方式二：手动部署（开发环境）

#### 后端部署
```bash
# 1. 初始化数据库
# 执行 backend/db/init.sql

# 2. 确保Redis已启动

# 3. 启动后端
cd backend
mvn clean package -DskipTests
java -jar target/campus-trade-1.0.0.jar
```

#### 前端部署
```bash
cd frontend
npm install
npm run dev
```

## 2. 环境变量配置

### 后端环境变量
| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| SPRING_DATASOURCE_URL | 数据库连接 | jdbc:mysql://localhost:3306/campus_trade |
| SPRING_DATASOURCE_USERNAME | 数据库用户名 | root |
| SPRING_DATASOURCE_PASSWORD | 数据库密码 | root |
| SPRING_REDIS_HOST | Redis地址 | localhost |

### Nginx配置
配置文件：`frontend/nginx.conf`
- 前端静态资源：监听80端口
- 后端API代理：`/api/` → `backend:8080`
- 文件上传代理：`/uploads/` → `backend:8080`

## 3. 数据库初始化
首次启动时，Docker会自动执行 `backend/db/init.sql` 完成数据库和表的创建，并初始化分类数据和管理员账户。

## 4. 验证部署
1. 访问 http://localhost 确认前端页面正常
2. 注册一个新用户，测试登录功能
3. 发布商品，检查流程是否正常
4. 使用 admin/admin123 登录管理后台
