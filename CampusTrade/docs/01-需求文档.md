# 校园二手交易平台 - 需求文档

## 1. 项目概述

### 1.1 项目背景
随着高校学生群体消费能力的提升，二手物品交易需求日益增长。为方便在校学生进行闲置物品的交易，开发本校园二手交易平台，提供安全、便捷的二手交易环境。

### 1.2 项目目标
- 构建一个面向高校学生的二手交易平台
- 支持商品发布、浏览、搜索、购买等核心功能
- 提供管理员后台进行商品审核、用户管理
- 实现前后端分离架构，支持Docker部署

### 1.3 项目名称
CampusTrade - 校园二手交易平台

## 2. 用户角色

### 2.1 普通用户
- 注册/登录账号
- 修改个人信息、密码
- 上传头像

### 2.2 学生用户（卖家/买家）
- 发布、编辑、删除、下架商品
- 浏览、搜索商品
- 收藏商品
- 购买商品、查看订单
- 确认收货、商品评价

### 2.3 管理员
- 用户管理（启用/禁用）
- 商品审核（通过/驳回）
- 商品管理
- 举报管理
- 系统公告管理
- 数据统计查看

## 3. 功能模块

### 3.1 用户模块
- 用户注册（用户名、密码、昵称、手机、邮箱、学号、学校）
- 用户登录（JWT Token认证）
- 修改个人信息
- 修改密码
- 上传头像

### 3.2 商品模块
- 商品发布（标题、描述、分类、价格、图片）
- 商品编辑
- 商品删除
- 商品下架
- 商品详情查看
- 商品分类浏览
- 商品搜索（关键词）

### 3.3 收藏模块
- 添加收藏
- 取消收藏
- 我的收藏列表

### 3.4 订单模块
- 创建订单（购买商品）
- 订单详情
- 我的购买订单
- 我的出售订单
- 取消订单
- 确认收货

### 3.5 评论模块
- 发表评论
- 删除评论

### 3.6 举报模块
- 举报商品

### 3.7 公告模块
- 查看公告列表

### 3.8 管理后台
- 数据统计总览
- 用户管理
- 商品审核与管理
- 举报处理
- 公告发布与管理

## 4. 非功能需求

- 使用JWT进行无状态认证
- 密码使用BCrypt加密
- 接口返回统一JSON格式
- RESTful API设计
- Docker容器化部署
