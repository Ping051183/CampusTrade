# 校园二手交易平台 - 测试文档

## 1. 测试环境

### 1.1 硬件环境
- CPU: 4核及以上
- 内存: 8GB及以上
- 磁盘: 50GB及以上

### 1.2 软件环境
- JDK 17+
- Maven 3.9+
- MySQL 8.0+
- Redis 7+
- Node.js 20+
- Docker 24+

## 2. 测试策略

### 2.1 单元测试
使用 JUnit 5 + Mockito 对 Service 层进行单元测试。

### 2.2 集成测试
使用 Spring Boot Test 对 Controller 层进行集成测试。

### 2.3 接口测试
使用 Postman/Apifox 对所有API接口进行测试。

## 4. 测试命令

```bash
# 运行所有测试
cd backend
mvn test

# 运行特定测试类
mvn test -Dtest=UserServiceImplTest

# 运行接口测试
mvn test -Dtest=*ControllerTest
```

## 5. 测试覆盖率要求
- Service层覆盖率 ≥ 85%
- Controller层覆盖率 ≥ 75%
- 整体项目覆盖率 ≥ 80%
